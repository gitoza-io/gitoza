Adds a local **Playground** workspace and syntax-highlighted code blocks in case descriptions.

### 🚀 New Features

- **Playground workspace** — Try Gitoza without a remote repository. Sample cases are included; use **Save** to commit changes locally.
- **Code-block highlighting** — Fenced code in case detail and exports is syntax-highlighted (YAML, JSON, JavaScript, Bash, and more).

### ✨ Improvements

- **Assignee picker** — Dropdown stays visible when the field is inside scrollable panels.
