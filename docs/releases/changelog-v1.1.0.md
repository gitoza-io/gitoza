Introduces **Tickets** and **Releases** so you can track work alongside your test cases in the same workspace.

### 🚀 New Features

- **Tickets** — Create and manage bugs, stories, tasks, and spikes with status, priority, assignee, tags, and search. Tickets live in your repository and sync with your team like test cases.
- **Ticket projects** — Organize tickets into projects with automatic IDs (for example `DEMO-A3F9K2`). Browse by project in a three-column layout similar to Test Repository.
- **Releases** — Plan and track releases from the sidebar. Link tickets to a release and review everything in one place.
- **Ticket links** — Set a parent ticket, see children, and use `[[TICKET-ID]]` links in descriptions. Open related tickets with a click.
- **Linked test cases** — See which cases reference a ticket so testing stays connected to the work item.
- **Join Discord** — Open the community invite from **Help** when you need a hand.

### ✨ Improvements

- **Sidebar layout** — Task items (Tickets, Releases) and test items are grouped so navigation is easier to scan.
- **Pin favorites** — Pin ticket projects and releases you use often so they stay at the top of the tree.
- **Markdown links** — Insert links more easily when editing ticket descriptions.
- **Windows Git** — Fewer brief console windows flashing during Git operations over SSH.
